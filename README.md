# E-Voting Pilkades Desa Telukbuyung 2026

Simulasi antarmuka e-voting Pilkades Desa Telukbuyung. Foto kandidat nomor urut 1 sudah tertanam di dalam `index.html`.

## Menjalankan secara lokal
1. Unduh atau ekstrak repositori ini.
2. Buka `index.html` menggunakan browser modern seperti Chrome atau Edge.
3. Untuk pemindaian kamera/QR, gunakan HTTPS atau localhost dan izinkan akses kamera bila diminta.

## Publikasi dengan GitHub Pages
1. Buat repositori baru di GitHub.
2. Unggah `index.html` dan `README.md` ke root repositori.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
6. Tunggu proses publikasi selesai, kemudian buka URL GitHub Pages yang ditampilkan.

## Catatan
- Ini adalah simulasi/demo, bukan sistem pemungutan suara resmi atau sistem yang telah diaudit keamanannya.
- Halaman memuat beberapa pustaka dari CDN, sehingga fitur terkait membutuhkan koneksi internet.
